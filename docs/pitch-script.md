# Streamora — 1-minute pitch script

**0:00-0:12**

Getting paid in crypto usually means one lump sum. That creates trust problems and cash-flow mismatches.

> 暗号資産での支払いは通常一括払いです。これが信頼の問題とキャッシュフローのミスマッチを生みます。

**0:12-0:28**

Streamora fixes this. It lets creators, freelancers, and DAOs stream token payments in real time, on Solana.

> Streamoraはこれを解決します。クリエイターやフリーランサー、DAOがSolana上でリアルタイムにトークンを送金できるようにします。

**0:28-0:44**

Payers set a rate and duration. Recipients withdraw accrued balance anytime. Payers can pause, top-up, or cancel.

> 支払う側はレートと期間を設定します。受け取る側はいつでも累積残高を引き出せます。支払う側は一時停止、追加入金、キャンセルも可能です。

**0:44-0:55**

We even support milestones, unlocking funds only after proof-of-work is uploaded.

> マイルストーン機能もあり、成果物のアップロード後にのみ資金がアンロックされます。

**0:55-1:00**

Streamora: programmable payment streams for the Solana economy.

> Streamora、Solanaエコノミーのためのプログラム可能な支払いストリームです。
